Gistsmith 0.1.8 fixes live translation.

## Fixes
- **Live translation shows only the translation.** When the speech was cut off mid-sentence or ran several sentences together, the translation could include the AI's own notes and corrections (for example "Wait, I must correct…" or "Note: the sentence is incomplete"). Translations now come back as the translated text only, and an unfinished sentence is translated as far as it goes.

Requires macOS 15 or later on Apple silicon.
