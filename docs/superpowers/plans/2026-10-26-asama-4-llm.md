# Aşama 4 — LLM (Claude): Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Canlı Türkçe çeviri, "Ne kaçırdım?" ve soru kutusu (Claude).
**Architecture:** `AINotepadCore/LLM`: saf istek gövdesi üreticileri ve yanıt ayrıştırıcıları + tek HTTP bağlayıcısı; uygulama çeviri kuyruğunu ve kartları yönetir; görünümler `LiveViewState` ile.
**Tech Stack:** URLSession, Swift Testing, SwiftUI.
**Spec:** `docs/superpowers/specs/2026-10-25-ai-notepad-design.md` §4.4

## Global Constraints
- Model kimlikleri aynen: `claude-haiku-5-5` (çeviri), `claude-opus-5-5` (özet/soru). `anthropic-version: 2026-10-21`.
- Haiku: `thinking: {type: "disabled"}`, `output_config.effort: "low"`, `max_tokens` 1024. Opus: `thinking` gönderilmez (adaptive), `output_config.effort: "medium"`, `fallbacks: "default"` + beta `server-side-fallback-2026-07-01`, `max_tokens` 16000.
- `temperature`/`top_p`/`top_k` gönderilmez. Önce `stop_reason == "refusal"` denetlenir.
- Keychain hesabı `anthropic`; bulut testleri `AINOTEPAD_CLOUD_TESTS=1`.
- "Ne kaçırdım?" penceresi 3 dk; çeviri bağlamı önceki 3 kesin "Diğerleri" bölümü.

## Review Focus
1. Çeviri sırası: cümleler gelişten farklı sırada çevrilip yanlış bölüme yazılmamalı → Task 3 `translationsKeyedBySegment`.
2. Geçersiz/eksik Anthropic anahtarı: canlı metin akmaya devam eder, tek açık hata → Task 1 `invalidKeyThrows401`, Task 3.
3. Model reddi (`refusal`): açık Türkçe hata, çökme yok → Task 1 `refusalIsError`.
4. Boş transkriptte "Ne kaçırdım?": istek atılmaz, "Henüz konuşma yok" → Task 2 `emptyWindowNeedsNoRequest`.
5. Uzun toplantıda soru: transkript çok büyükse son 2 saat ile sınırlanır (bağlam/maliyet) → Task 2 `questionTranscriptCapped`.

### Task 1: Claude bağlayıcısı
`LLM/ClaudeClient.swift`: `ClaudeModel` (`.haiku`, `.opus` ham değer = kimlik), `ClaudeRequest` (model, system, userText, maxTokens, effort, jsonSchema?), `claudeRequestBody(request:) throws -> Data` (saf), `claudeHeaders(apiKey:model:) -> [String: String]` (saf), `parseClaudeResponse(data:) throws -> String` (metin blokları birleşir; thinking/fallback atlanır; refusal → `LLMError.refusal(category:)`), `sendClaude(apiKey:request:) async throws -> String` (3 deneme, 4xx denenmez). `LLMError`: `.http(status, body)`, `.refusal(category: String?)`, `.malformed(body)`, `.empty`.
- Testler (saf): `haikuBodyDisablesThinkingLowEffort`, `opusBodyHasFallbacksAndNoThinking`, `opusHeadersIncludeFallbackBeta`, `parseJoinsTextSkipsThinking`, `refusalIsError`, `schemaGoesToOutputConfigFormat`. Bulut: `haikuAnswers` (kısa istek metin döner), `invalidKeyThrows401`.

### Task 2: Komutlar ve ayrıştırma (saf) + bulut
`LLM/MeetingPrompts.swift`: `transcriptLines(blocks: [SpeakerBlock]) -> String` (`[mm:ss] Etiket: metin`), `translationRequest(sentence:context:)`, `MissedSummary {topic, decisions, askedOfYou}` + `missedSummaryRequest(blocks:nowSec:windowSec:) -> ClaudeRequest?` (pencerede metin yoksa nil) + `parseMissedSummary(text:) throws`, `questionRequest(blocks:question:)` (son 7200 sn).
- Testler: `emptyWindowNeedsNoRequest`, `windowKeepsLastThreeMinutes`, `parseMissedSummaryJSON`, `questionTranscriptCapped`, `translationPromptHasContext`. Bulut: `translatesFinnishToTurkish` ("Seuraavalla viikolla meidän pitää palauttaa raportti." → küçük harfli Türkçe "rapor" içerir), `missedSummaryFromDialog` (fi-dialog metinleriyle geçerli JSON, `topic` boş değil).

### Task 3: Canlı çeviri (uygulama)
`AppModel`: `translations: [SegmentID: String]`, seri `TranslationQueue` (actor) — "Diğerleri" kesin bölüm geldiğinde iş ekler; sonuç kimliğe yazılır; hata → `appendUnique`. Anahtar yoksa çeviri atlanır ve tek hata. `LiveViewState`'e `translations` ve `displayMode` (`bilingual` | `turkishOnly`); `latestOthersSentence` Türkçesi varsa onu kullanır.
- Testler (AINotepadUI, saf): `translationsKeyedBySegment` (bloktaki bölümlerin Türkçesi sırayla birleşir), `latestUsesTurkishWhenAvailable`.

### Task 4: Panel ve ada arayüzü
`TranscriptPanel`: blok metninin altında Türkçe (iki dil: orijinal %55 soluk 13 pt + Türkçe 14 pt; sadece Türkçe: Türkçe yoksa orijinal soluk); alt çubuk: "Ne kaçırdım?" düğmesi + soru alanı; kart (özet/cevap/yükleniyor/hata, kapat). Panel `KeyablePanel: NSPanel` (`canBecomeKey = true`). Önizleme aracıyla görsel kontrol.

### Task 5: Ayarlar, kabul listesi, inceleme
Ayarlar'a Anthropic anahtarı ve görünüm (İki dil / Sadece Türkçe). Kabul listesine LLM maddeleri. Bağımsız inceleme + düzeltme turu.
